# Dos Con Hilo — Creaciones a crochet

Landing page estática creada con HTML semántico, CSS y JavaScript vanilla. No requiere instalación, compilación ni dependencias: abre `index.html` directamente en el navegador.

## Personalización

1. El logo original está en `assets/Logo.jpeg` y se muestra en el encabezado y el pie de página.
2. Reemplaza las imágenes de muestra del catálogo por fotografías propias. Los nombres de archivo esperados son `assets/productos/amigurumis.jpg`, `flores.jpg`, `llaveros.jpg`, `personalizados.jpg` y `otras-creaciones.jpg`. Las imágenes actuales son recursos temporales remotos de Unsplash, señalados en cada tarjeta.
3. Los datos oficiales están configurados en el objeto `CONFIG` de `js/script.js`: WhatsApp `528331701419`, Instagram `dosconhilo` y el perfil de Facebook compartido por la marca. Ahí también puedes cambiar el mensaje predeterminado de WhatsApp.

Todos los puntos de contacto de WhatsApp, Instagram y Facebook se generan desde ese único objeto.
